# 项目主要规划

这是一个通过网络实现 YubiKey(智能卡CanoKey `SmartCardReader`) 在不同终端共享使用的互联网软件

目标效果是：当 YubiKey 连接到任意一个使用QiCardMesh设备时，其他使用 QiCardMesh 的终端都可以使用这个YubiKey。

传输方案：基于MQTT+HTTP进行数据交互传输。http 账号，鉴权管理。MQTT 用于数据通讯

### 编程语言

用户软件：QiCardMeshAPP  tauri （vue + rust）目录最外侧

windows系统服务：QiCardMeshService rust 目录：Windows\service

服务器：QiCardMeshServer (Django) 目录在Server

# 目录与功能

### QiCardMeshAgent 

一个Rust编写的daemon，主要任务：

1. 其他设备 通过 MQTT 查询本机由那些卡和卡的摘要   MQTT 主题：QiCardMesh/device/<用户ID>/method
2. 查询卡的具体信息   MQTT 主题：QiCardMesh/device/<用户ID>/method
3. 当设备有 连接 或者 断开 时发送MQTT notify MQTT 主题：QiCardMesh/device/<用户ID>/notify
4. 其他设备 透过MQTT执行APDU到卡 MQTT 主题：QiCardMesh/device/<用户ID>/method
5. 当QiCardMeshAgent 启动后，mqtt连接完成，需要上报此电脑加入 MQTT 主题：QiCardMesh/device/<用户ID>/notify
6. 维护mqtt服务

### Server

服务端，提供身份认证服务

使用 Redis 作为数据缓存

接口设计

整套系统提供一个 /api 需要登录的接口采用 bearerToken access_token + refresh_token

设计一个 ResponseBase {"code": "业务码", "message": "业务码解释", "data": "业务数据" } 作为所有接口的统一回复模板

1. /api/auth/login

登录接口，username也可以是email。登录成功后返回  bearer 认证的内容

{"username": "", "password": ""}

2. /api/auth/refresh 通过 refresh_token 刷新 access_token 接口

{
    "refresh_token": "xxxxxxxx"
}

3. /api/auth/logout

退出登录
